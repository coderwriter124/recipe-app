# Recipe App

The recommendation assistant now appears as a spacious right-side panel on wide screens and moves above the content on smaller screens.

It provides an AI-style chat experience using the app's local recipe catalog: natural-language prompts, quick suggestions, cuisine and dietary controls, conversational responses, and clickable recommended recipes. It is deterministic local matching—not a hosted LLM—so it requires no API key, account, or paid service.

Run the updated app:

```cmd
cd /d C:\Users\priya\recipe-app
git pull
npm install
npm run dev
```

Open http://localhost:5173.
